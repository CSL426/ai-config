給同時使用多套 AI 工具的人

ai-config (acg)

把你習慣的操作規則、AI 技能與設定帶到每台裝置。換電腦或換工具，不必重新開始。

Claude Code · Codex · Antigravity

← → 翻頁

痛點

換一台電腦，
設定就變一套

工作站、筆電、遠端主機各有一份設定。這台改了操作規則，那台新增了 AI 技能，另一台還停在上個月。每次換機器都得先猜：「哪一台才是最新的？」

痛點

靠手動複製，遲早會亂

  • 誰新誰舊，全靠記憶 — 用隨身碟、通訊軟體或直接複製，蓋錯方向就很難救回來。
  • 登入資料可能一起被帶走 — 設定和憑證放在附近，整包複製時容易把不該分享的內容也帶上。
  • 同一件事要設定好幾次 — Claude Code、Codex、Antigravity 各記各的，換工具就要重做。
  • 換新電腦又要從頭設定 — 重裝、重抄、重新回想上次到底改了什麼。

核心想法

像一個有記憶的
私人置物櫃

設定放進你選的私人位置，工作站、筆電、遠端環境與新電腦都能拿到同一份。它還記得之前放過什麼，改錯也找得回來。

同步方式

Google Drive 或 Git，
你自己選

只在自己的裝置間同步，可以直接登入 Google Drive；已有私人儲存庫或想和別人共用，就選 Git。第一次開啟 GUI 時會帶你完成選擇。

哪些內容會同步

帶走工作習慣，不搬走登入資料

會跟著你走

  • 回答與操作規則 — 讓每套工具維持你熟悉的工作方式。
  • 常用 AI 技能 — 不必在每台裝置重新安裝與整理。
  • 可共用的工具設定 — 一次準備，需要時套用。

只留在這台

  • 帳號與登入憑證 — 不會被收集、比較或上傳。
  • 這台裝置的權限 — 不把某台的授權帶到另一台。
  • 模型、顯示與專案偏好 — 每台裝置保留自己的選擇。

平常使用

你只需要知道四件事

01

下載最新設定

acg pull

拿回其他裝置的更新。

02

看看哪裡不同

acg status

只查看，不會修改。

03

套用到這台

acg apply

先備份，再更新。

04

保存我的修改

acg push

先預覽，確認才送出。

安全感

不確定，就停下來問你

  • 你先看，我才上傳 — 大量項目會先收成摘要；確認後才保存並送出。
  • 狀況不清楚就停止 — 不擅自合併，也不偷偷替你改寫紀錄。
  • 更新前先留備份 — 萬一失敗，會清楚告訴你備份放在哪裡。
  • 登入資料不參與同步 — 帳號、密碼與授權資料不會進入同步內容。
  • 每台裝置保留自己的偏好 — 模型、顯示方式與專案選擇不會被其他裝置蓋掉。

分享技能

Claude 已經會的，
其他工具也能接著用

如果你已經在 Claude 使用某個技能，不必再替其他工具手動安裝。請 AI 幫你分享，或使用 acg share；完成後，Codex 與 Antigravity 也能使用。

開始使用

第一次開啟，會帶你完成設定

想自己安裝時，複製這一行 
$ curl -fsSL https://raw.githubusercontent.com/CSL426/ai-config/main/install.sh | bash
  • 不想碰指令也可以 — 把下一張投影片的那句話交給能操作電腦的 AI。
  • 先選同步方式 — 使用自己的 Google Drive，或連上私人 Git 儲存庫。
  • 保存位置不用煩惱 — 新設定預設放在隱藏的專用資料夾，舊位置仍然能用。
  • 中文跨平台也能正確處理 — Linux、macOS 與繁中 Windows 都有對應方式。
  • 連線完成後即可同步 — 換裝置時下載並套用，就能接著使用。

不會用也沒關係

不會指令，
也能請 AI 幫你

直接說你想完成什麼。AI 會先讀 acg 的操作指南，再檢查目前狀況。真正會改動這台裝置、保存變更或上傳時，仍要先取得你的確認。

桌面版

不開終端機，也能管理設定

  • 同步狀況一眼看見 — 同步方式、登入、保存位置與版本更新都能直接查看。
  • 長清單不再塞滿畫面 — 同資料夾的大量項目會收成摘要，真正有差異的內容仍會顯示。
  • 看過才真的上傳 — 先顯示精簡預覽；確認時若內容已變動，會停止並請你重看。
  • 同一套技能交給更多 AI — 可分享給其他工具，或準備成桌面版可安裝的檔案。
