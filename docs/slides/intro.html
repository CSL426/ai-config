一套自訂技能，三個工具都能用

你寫的技能可以同步給 Claude Code、Antigravity 與 Codex。

各工具保持原生環境，共用技能隨處保持一致。

讓 AI 共讀同一本筆記

全域記住你的偏好，專案層留下已確認的決定。

acg memory enable

啟用後請開新會話驗證。pull 成功會立即更新共用筆記；不代表既有會話已重新讀取。

換個會話，接上同一條線

handoff 留下做到哪裡、卡在哪裡，以及下一步。

日誌記錄專案發生過什麼；交接則是一條工作線一份。交接、清空對話、再接手：同一個會話會自動接回自己留下的那條線。

Claude Code 可另開 context 提醒；提醒本身不會自動寫交接。

1 · 留進度

acg memory handoff write "工作線" "進度與下一步"

2 · 接手

acg memory handoff claim　接回這個會話自己的線
acg memory handoff claim "工作線"　指定別條

3 · 做完自動結案

交接時沒有下一步就直接結案；一個月沒人動的線也會自動歸檔。不打指令，說「交接」「接著做」也行。

別人正在做的線不會被搶走；超過一天沒動的可以接手，並說出前一位持有者。久未更新的線標上「可能已過期」。

記憶累積後，自動帶回去

autopush 讓共用筆記定期保存，不必每天記得上傳。

acg memory autopush enable 4

安排每日凌晨 4 點時段執行；用 status 查看、disable 移除排程。

自動推送，不逐次確認

與手動上傳不同，背景流程會自動提交並推送記憶，仍保留憑證掃描與推送守衛。

有變更，也要隔一段時間

記憶沒有變更，或距離上次推送未滿 12 小時，就略過推送。

沒有排程，也可能自動保存

acg 指令結束後可機會式推送；停用排程不等於關閉此路徑。

以 AI_CONFIG_NO_AUTOPUSH=1 抑制指令結束後的機會式推送。

選個時間，讓 AI先打聲招呼

keepalive 定時對 Claude、Codex、Antigravity 送出一句短提示，讓用量視窗從你選的時間開始。

預設停用。每次都挑該工具清單裡最便宜的模型；Codex 有好幾個帳號時，每個帳號各喚醒一次。時間與日誌留在本機，同一個帳號開一台就夠。

設定這台的時間

acg keepalive enable 07:00 12:05

查狀態，或立即送一次

acg keepalive status　顯示實際的視窗，沒對準排程會提醒
acg keepalive send

不需要時停用

acg keepalive disable

呼叫失敗時會記下工具自己的錯誤訊息，例如額度用完、何時恢復。它不同步設定，也不執行你的工作任務。
