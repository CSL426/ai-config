# 投影片插圖:產圖指示

這份給產圖的 agent(agy)讀。產出的圖存到**這個資料夾**,檔名照下表。
投影片是 `docs/slides/intro.html`,公開在 https://csl426.github.io/ai-config/ ,
對象是想把 AI 工具設定帶著走、但不一定會打指令的人。語氣友善、輕鬆,不要科技感過重。

## 所有圖都要遵守

1. **畫面裡不能有任何文字、字母、數字、標誌或 UI 文字。** 產出來的中文幾乎都是亂碼;
   標籤會由 HTML 疊上去。若畫面上需要「一張紙」「一本書」,紙面只畫幾條線代表文字。
2. **畫風統一**:扁平的編輯風插畫(flat editorial illustration),線條為均勻粗細的
   墨色描邊(約畫面寬度的 0.4%),帶一點手繪的不完美感;不要漸層、不要寫實陰影、
   不要 3D、不要照片質感。整組 8 張要像同一位插畫家畫的。
3. **只用這些顏色**(投影片的配色,填色用 soft 版本為主、飽和色點綴):

   | 名稱 | hex | 用途 |
   |---|---|---|
   | paper | `#F7F5EC` | 背景 |
   | ink | `#12171B` | 描邊、深色細節 |
   | pear | `#F6CE00` | 主角物件(設定包、筆記本) |
   | pear-soft | `#F7E8AF` | 大面積淡填色 |
   | sky / sky-soft | `#009FEF` / `#BFE8FF` | 裝置、工具 A |
   | mint / mint-soft | `#66DA85` / `#CCF0D2` | 通過、工具 B |
   | coral / coral-soft | `#FF3A5D` / `#FFDDDD` | 警示、工具 C |

4. 背景是純色 `#F7F5EC`,或透明;畫面四周留白約 8%,主體不要貼邊。
5. 尺寸 **1600×1000(16:10 橫幅)**,輸出 PNG。
6. 「三個 AI 工具」一律畫成**三個友善的小機器人或小角色**,分別用 sky、mint、coral
   當主色;不要畫任何公司的標誌或相似的圖形。
7. 人物(使用者)畫成簡化、無五官細節的角色,性別中性。

## 第四輪:整理比比拉布圖示(2026-09-24)

來源:`/home/human/ai-config/gui/src/assets/bibilabu.png`(250×250),
另一份 `/home/human/ai-config/assets/icon.png`(256×256)是同一張圖。

**只整理,不換風格。** 角色、姿勢、表情、配色、3D 質感都保持原樣,
看起來要是「同一張圖的高畫質版」,不是重新畫一隻。上面「所有圖都要遵守」的
扁平插畫與五色規則**不適用**這張。

要修的:

1. 解析度拉到 **1024×1024**,邊緣清楚,去掉壓縮雜點與鋸齒。
2. **背景完全透明**(PNG 帶 alpha),角色外圍不能留白邊或灰邊;
   `icon.png` 上下那兩條灰色邊線要去掉。
3. 角色置中,四周留約 6% 空白,腳底不要貼到邊。
4. 縮到 16×16、32×32 仍認得出是香蕉加貓臉:輪廓要清楚,可以
   加一圈很細的深色描邊(約 1–2%)幫助小尺寸辨識,但不要改變角色本身。
